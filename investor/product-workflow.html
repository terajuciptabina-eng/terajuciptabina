TERAJUWORKS · PRODUCT EVIDENCE
From Project Input to Project Insight
A structured construction workflow connecting manual or AI-assisted input, planner-specific costing, Cost Estimate and contractor project control.
01 · INPUT
Project Input
Create rooms and areas manually, or upload a PDF/image floor plan where supported.
02 · OPTIONAL AI
Floor-plan extraction
AI-assisted extraction can accelerate room/area capture. Users can still work manually.
03 · PLANNER
BuildPlanner / RenovationPlanner
BuildPlanner models new construction. RenovationPlanner keeps existing and new areas separate.
04 · CALCULATION
Calculation Rules
Rules drive quantities, measurements, rates and cost calculations from a canonical source.
05 · BUDGET
Construction / Renovation Budget
The planner generates the relevant budget using the underlying project calculations.
06 · ESTIMATE
Simple / Detailed Cost Estimate
The same project calculation foundation produces concise or detailed estimate views.
07 · CONFIRM
Confirmed project baseline
A confirmed estimate can provide the structured item reference for downstream contractor project control.
08 · CONTROL
Work Program → Progress → S-Curve
Planned work and actual progress are connected to the project baseline and can feed Project Insight.
BUILDPLANNER · NEW CONSTRUCTION

Built-up Area + RM/sqft

One new-construction RM/sqft metric. Existing/New separation is not required.
RENOVATIONPLANNER · RENOVATION

Existing + New RM/sqft

Existing Area + Existing RM/sqft and New Area + New RM/sqft are kept separate. Budget regeneration is explicit, not automatic.
Key product point: the platform separates business meaning where construction logic differs, while keeping the broader calculation and project-control architecture connected. AI is an optional acceleration layer, not the core product dependency.
