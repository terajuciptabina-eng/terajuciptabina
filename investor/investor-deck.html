05 · THE CONSTRUCTION PROBLEM
Cost, scope, work, progress, claims and payment can become disconnected.
Cost visibility

Lump-sum figures can hide the quantities, rates and work items behind a project value.

Execution visibility

Work programme and actual progress can live separately from the original cost baseline.

Change control

Variations and scope changes can become difficult to reconcile against what was originally agreed.

Shared reference

Homeowner and contractor need a structured reference for what is included, what is planned and what has been completed.

TERAJUWORKS thesis

The estimate should not be the end of the workflow. It should become the structured baseline from which the rest of the project is controlled.

07 · BUILDPLANNER
New construction is modelled as new construction.
INPUT
Rooms / areas

Project areas and rooms form the initial project measurement.

CALCULATION
SMM-based costing

Calculation Rules drive quantities, measurements, rates and cost outputs.

METRIC
Built-up Area + RM/sqft

One new-construction RM/sqft metric; no Existing/New split is required.

Output

Construction Budget → Cost Estimate → Simple / Detailed estimate presentation.

BuildPlanner07 / 22
08 · RENOVATIONPLANNER
Renovation needs a different cost model because existing and new areas mean different things.
EXISTING
Existing Area

Existing work/area is tracked with its own cost-per-sqft context.

Existing RM/sqft
NEW
New Area

Newly added work/area is tracked separately from existing conditions.

New RM/sqft
Controlled regeneration

Room/Area changes do not silently regenerate the budget. The user explicitly clicks Generate / Regenerate Renovation Budget when the project input is ready.
