TECHNOLOGY & PRODUCT EVIDENCE

More than a calculator: measurement, calculation, control and data infrastructure.

The current repository contains multiple input and control pathways designed to feed the same planning ecosystem.

01 · MANUAL INPUT

Room / Area planning

Users can define rooms/areas directly and generate construction or renovation budgets from calculation rules.

02 · AI FLOOR PLAN

PDF / image → Room & Area

The floor-plan workflow can extract room names, areas, dimensions and confidence for review before planner import.

03 · BIM / IFC

Model → Room / Area

IFC Room / Space data can be extracted, reviewed, edited and handed to BuildPlanner or RenovationPlanner.

04 · LOCAL-FIRST

Privacy-aware BIM input

The IFC file is stored locally in the browser via IndexedDB; BIM source data is not uploaded to the server/database by the import bridge.

CALCULATION ARCHITECTURE

Canonical rules drive downstream outputs.

Admin-managed calculation rules and rate sets are intended to remain the source for budget and Cost Estimate calculations rather than duplicating business logic across screens.

Project Input → Rules → Quantity / Measurement → Cost → Budget → Estimate
BUILD VS RENOVATION

Different construction meaning, shared platform.

BuildPlanner: Built-up Area + one new-construction RM/sqft context. RenovationPlanner: Existing Area + Existing RM/sqft and New Area + New RM/sqft remain separated.

INVESTOR CLARITY

The important distinctions.

What exactly is the investment?

TERAJUWORKS as a technology venture: software, product, technology team, commercialisation, IP and scalable growth. It is not an investment into the general construction operations of TERAJU CIPTABINA RESOURCES.

Is TERAJUWORKS already profitable?

No. The current investor position is early commercial validation with 0 paying TERAJUWORKS software customers disclosed. The opportunity is to validate monetisation and repeatable acquisition from an existing working product base.

Does the BIM feature upload users' IFC files?

The current IFC Room / Area import bridge is designed local-first: the IFC file is stored in browser IndexedDB and room/area extraction is performed in the browser. The product explicitly states that IFC/room data is not sent to the server/database through that import flow.

Can the construction company use TERAJUWORKS?

Yes. TERAJU CIPTABINA RESOURCES can be a customer and contractor within the ecosystem, but the relationship should be documented as a related-party commercial relationship as the technology venture is formalised.

What still needs to be proven?

Paid conversion, retention, contractor subscription demand, acquisition economics, independent network activity, scalable support and the commercial value of the structured construction-data layer.
