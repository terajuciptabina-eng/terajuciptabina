ROUND UP · NO DECIMAL
System principle

User provides area in sqft or m². Rules convert units where required. Construction quantity is returned in metric units. No detailed measurement is required from the user unless a rule explicitly derives a dependency from an existing planner value. Rates remain editable separately and are not part of this panel. Room names are calculation inputs or auto-text references where stated; Electrical, Doors & Windows and External Work are not split into room-level output items. Items requiring project-specific information are not auto-calculated here.
