Calculation principle

This page records the calculation derivation behind the reference bungalow data. Every coefficient is shown together with the source quantities used to derive it. No rate or selling price is part of the calculation rule. Where the Excel source and an earlier rule differ, the Excel formula is shown exactly and the difference is explicitly flagged instead of silently changing the calculation.
